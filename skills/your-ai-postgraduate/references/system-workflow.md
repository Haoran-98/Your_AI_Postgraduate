# System Workflow

```text
idea
  -> domain routing
  -> Postgraduate vault
  -> literature map and paper master
  -> lawful PDF/full text + BibTeX
  -> strict paper cards
  -> compact paper memory
  -> evidence validation
  -> causal synthesis
  -> Obsidian relations + provider-neutral RAG
  -> retrieved research reasoning
  -> knowledge visualization + current task-fit profile
  -> cost/quality audit
  -> Git synchronization
```

The paper card, paper master, PDF, extracted full text, and BibTeX form the authoritative literature layer. Compact memory is the default machine recall layer. Hyper-Extract is optional and remains subordinate to evidence validation.

Each stage writes resumable artifacts. Failed units do not invalidate completed units. Corpus-level idea support, refutation, contrarian hypotheses, and experiments are produced after evidence retrieval rather than duplicated during every paper ingestion. The final knowledge profile summarizes existing artifacts deterministically and does not replace human research evaluation.
