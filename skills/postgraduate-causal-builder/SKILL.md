# Postgraduate Causal Builder

Read `../postgraduate-common/references/evidence-policy.md`, `routing-policy.md`, and `artifact-contracts.md`.

## Workflow

1. Start from validated paper memories and source chunks.
2. Separate treatments, mediators, moderators, outcomes, confounders, measurements, and contexts.
3. Record mechanisms and boundary conditions.
4. Distinguish association, author causal claim, identified effect, and mechanistic hypothesis.
5. Build domain-specific causal bridges from reusable methods to the target problem.
6. Create supported claims, counterevidence, assumptions, and contrarian hypotheses with tests.

Write to `wiki/variables/`, `mechanisms/`, `causal-core/`, `causal-bridges/`, `claims/`, and `hypotheses/`. Never create a global causal vault.
