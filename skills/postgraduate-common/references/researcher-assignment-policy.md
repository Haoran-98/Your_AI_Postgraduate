# Researcher Assignment Policy

Apply this gate before every new research task, including a new idea inside an existing domain.

## Required Check

1. Inventory all existing `Postgraduate_*` vaults.
2. For plausible candidates, inspect `wiki/profile/`, `wiki/index.md`, `wiki/hot.md`, and direct RAG matches for the new task.
3. Reuse an existing postgraduate only when both conditions hold:
   - the vault owns the task's primary research object or population;
   - stored evidence has direct transferable coverage of the task's constructs, methods, data, or evaluation.
4. Do not reuse a vault based only on generic causal, LLM, statistical, or research-method overlap.
5. If no vault passes both conditions, create a new `Postgraduate_<EnglishDomainSlug>` vault.

## Durable Decision

Write `wiki/meta/<idea-id>-postgraduate-assignment.md` in the selected or newly created vault. Record:

- candidate vaults and evidence inspected;
- direct knowledge matches and current profile scores;
- assignment decision and rationale;
- reuse boundaries and missing capabilities;
- whether a new vault was created.

The assignment note is required before literature search or idea ingestion proceeds. Reassess the assignment when the research object changes materially.
