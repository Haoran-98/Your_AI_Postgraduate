# AutoResearch Protocol

Use for literature exploration, survey drafting, idea mining, and novelty checks.

1. Convert the user idea into public search keywords.
2. Browse current high-quality sources when recency matters.
3. Build a literature map: foundations, recent work, datasets, methods, gaps.
4. Generate multiple idea variants with feasibility and evidence needs.
5. Mark novelty as `searched`, `partially searched`, or `unsearched`.
6. Save durable notes into the domain vault if the user asked for persistence.

Do not paste private drafts or unpublished details into public searches without explicit authorization.
