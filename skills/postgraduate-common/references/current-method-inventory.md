# Current Method Inventory

This repository packages only methods already used in the source system:

- independent domain-specific Obsidian postgraduate vaults;
- IDEA markdown ingestion and domain routing;
- AutoResearch literature maps and evidence-backed idea variants;
- official-source literature search and cross-venue linkage;
- lawful PDF acquisition, text extraction, OCR fallback, and blocked status;
- paper-master tables, paper cards, official BibTeX lookup, and metadata correction;
- strict full-text extraction of questions, methods, variables, datasets, experiments, findings, limitations, mechanisms, causal interpretation, transfer, support/refutation, contrarian hypotheses, and tests;
- compact paper memory with independent long-paper parts, immutable candidate-ID consolidation, exact/layout-recovered validation, claim-support review, and source rehydration;
- causal variables, mechanisms, assumptions, claims, hypotheses, and domain bridges;
- deterministic Obsidian relation maps and semantic clusters;
- provider-neutral JSONL RAG and lexical retrieval;
- optional Hyper-Extract exhaustive graphs with conservative sanitization;
- weak/medium/strong task tiers;
- per-request payload, token, latency, retry, failure, and cost auditing;
- resumable failed-unit recovery and Git synchronization with comments.

Do not add a new research method under the banner of this inventory without separate evidence and explicit user approval.
