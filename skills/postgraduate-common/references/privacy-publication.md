# Privacy And Public Publication

Do not publish:

- API keys, authorization headers, cookies, or private endpoints;
- private drafts, unpublished ideas, personal notes, or confidential datasets;
- PDFs or full text without redistribution rights;
- request logs that contain private source text;
- usernames, expanded home paths, or machine-specific defaults.

Public repositories may contain generic Skills, deterministic scripts, schemas, templates, synthetic examples, and documentation of measured workflow behavior. Use environment variables and example configuration files with blank values.
